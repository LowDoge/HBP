# 1. Введение

## 1.1. Назначение системы

Микросервисная платформа для управления бронированием номеров в отелях с динамическим ценообразованием.

Функции:
- Поиск и бронирование номеров
- Управление инвентарем отелей
- Динамическое ценообразование
- Обработка платежей
- Управление профилями гостей
- Формирование отчетов

## 1.2. Цели

Бизнес-цели:
- Автоматизация бронирования
- Максимизация доходности через динамический прайсинг
- Предотвращение двойных бронирований
- Программа лояльности

Технические цели:
- Микросервисная архитектура
- DDD
- Event-Driven архитектура
- Паттерны: Saga, Outbox, CQRS, Circuit Breaker

## 1.3. Аудитория

- Операторы отелей
- Гости
- Администраторы

## 1.5. Микросервисы

| Сервис | Ответственность |
| :--- | :--- |
| Hotel Service | Управление отелями и номерами |
| Inventory Service | Управление доступностью номеров |
| Booking Service | Создание и управление бронированиями |
| Pricing Service | Динамическое ценообразование |
| Payment Service | Обработка платежей |
| Guest Service | Управление профилями гостей |
| Notification Service | Уведомления |
| Reporting Service | Отчеты и аналитика |
