# 8. Ограничения и риски

## 8.1. Ограничения

| Ограничение | Причина |
| :--- | :--- |
| Платежи — имитация | Отсутствие реального шлюза |
| Email/SMS — в лог | Отсутствие провайдеров |
| JWT без OAuth2 | Упрощение для демо-проекта |
| Один дата-центр | Геораспределение не требуется |
| Eventual consistency | Допустимо для отчетов |

## 8.2. Риски

| Риск | Вероятность | Митигация |
| :--- | :--- | :--- |
| Kafka Consumer Lag | Средняя | Мониторинг, KEDA, оптимизация |
| Двойное бронирование | Высокая | Redis Lock + Optimistic Lock |
| Payment Service сбой | Средняя | Компенсация, Retry, DLQ |
| PostgreSQL нагрузка | Средняя | Индексы, кэш, read-реплики |
| Redis переполнение | Низкая | LRU eviction, мониторинг |
