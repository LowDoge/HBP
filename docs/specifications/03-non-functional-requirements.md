# 4. Нефункциональные требования

## 4.1. Производительность

| Показатель | Значение |
| :--- | :--- |
| Время ответа API (p95) | < 200 мс |
| Пропускная способность (чтение) | 1000 RPS |
| Пропускная способность (запись) | 100 RPS |
| Задержка gRPC | < 50 мс |
| Redis Cache Hit Rate | > 90% |
| Kafka Consumer Lag | < 1000 сообщений |

## 4.2. Надежность

| Показатель | Значение |
| :--- | :--- |
| Доступность (SLA) | 99.95% |
| MTBF | > 1000 часов |
| MTTR | < 30 минут |
| RPO | < 5 минут |
| RTO | < 15 минут |

## 4.3. Масштабируемость

- Горизонтальное масштабирование: все stateless сервисы
- Шардирование: по hotel_id (Kafka, БД)
- CQRS: разделение чтения/записи

## 4.4. Отказоустойчивость

| Механизм | Назначение |
| :--- | :--- |
| Graceful Shutdown | Завершение текущих запросов |
| Circuit Breaker | Защита от каскадных отказов |
| Retry with Backoff | Обработка временных ошибок |
| Dead Letter Queue | Необработанные сообщения |
| Health Checks | Liveness, Readiness |

## 4.5. Алерты

| Событие | Порог | Уровень |
| :--- | :--- | :--- |
| Error Rate | > 1% за 5 минут | Warning |
| Response Time | > 500 мс за 5 минут | Warning |
| Kafka Consumer Lag | > 5000 сообщений | Warning |
| CPU/Memory | > 85% | Warning |
| Сервис недоступен | > 1 минуту | Critical |
