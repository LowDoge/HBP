# 7. Definition of Done

## 7.1. Разработка

- [ ] Код написан на .NET 10
- [ ] Юнит-тесты (покрытие > 70%)
- [ ] Интеграционные тесты для Saga и Outbox
- [ ] Swagger/OpenAPI для REST
- [ ] .proto файлы для gRPC

## 7.2. Инфраструктура

- [ ] Dockerfile (multi-stage)
- [ ] Docker Compose работает локально
- [ ] Миграции БД
- [ ] Kafka топики создаются автоматически

## 7.3. Наблюдаемость

- [ ] Логи в Seq
- [ ] Метрики в Prometheus
- [ ] Дашборды в Grafana
- [ ] Алерты настроены
- [ ] Трассировка в Jaeger

## 7.4. Финальная проверка

- [ ] Полный цикл бронирования работает
- [ ] Отмена бронирования с откатом
- [ ] Цена рассчитывается корректно
- [ ] Отчеты содержат данные
- [ ] Уведомления логируются
- [ ] После перезапуска сервисов система восстанавливается
