# ADR-003: Dapper

## Контекст

Необходим доступ к PostgreSQL.

## Варианты

- Dapper
- EF Core
- ADO.NET

## Решение

Dapper.

## Обоснование

1. Минимальный оверхед
2. Полный контроль SQL
3. Высокая производительность

## Последствия

- Ручное написание SQL
- Ручные миграции (DbUp)
- Нет автоматического трекинга
