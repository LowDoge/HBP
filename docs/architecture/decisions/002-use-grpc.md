# ADR-002: gRPC

## Контекст

Необходим протокол для синхронной коммуникации между микросервисами.

## Варианты

- gRPC
- REST (HTTP/JSON)
- GraphQL

## Решение

gRPC.

## Обоснование

1. Protobuf быстрее JSON
2. Строгие контракты
3. HTTP/2 мультиплексирование и стриминг

## Последствия

- .proto файлы для всех сервисов
- Сложнее отладка
- REST для внешнего API
