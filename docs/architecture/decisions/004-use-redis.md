# ADR-004: Redis

## Контекст

Необходимо in-memory хранилище для кэширования и распределенных блокировок.

## Варианты

- Redis
- Memcached
- IMemoryCache

## Решение

Redis.

## Обоснование

1. In-memory производительность
2. Distributed Locking
3. TTL поддержка
4. JSON поддержка

## Последствия

- Дополнительный компонент
- Мониторинг памяти и hit rate
